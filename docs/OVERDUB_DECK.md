# PhiBox R6 / Overdub Deck

PhiBox R6 adds real **same-track overdubbing**, one-level **UNDO/REDO** per loop track, and direct **WAV export** for each loop lane. It builds on the four independent Loop Forge tracks introduced in R5.

## Record an overdub without erasing your loop

1. Create a first take in Loop Forge with **REC LOOP**, or use an existing stored track.
2. With that track playing, choose **OVERDUB LAYER LEVEL**. 85% is the default; lower values make the new part quieter.
3. Click **OVERDUB** on the track you want to enrich. PhiBox queues for the **next full bar**, then captures the live pad/synth input for exactly as many bars as the selected track already has. You can play other tracks while recording.
4. When the bar window completes, PhiBox mixes the original track's PCM and the new performance into one replacement take and keeps the previous take in memory.
5. Click **UNDO** to switch back to the original take if you dislike the new layer; **REDO** brings the mixed version back. The current audible version is saved locally each time.

Overdub is **additive**, not destructive while recording. During capture the old loop remains audible; if you cancel, the existing recorded take stays unchanged. The process does *not* rerecord other Loop Forge tracks: those feed into the master separately from the live instrument bus.

**Important monitoring detail:** the live input bus includes everything generated by the step sequencer and performance pads. If your original loop was recorded from the same running sequence and you overdub while that same pattern still plays, you will capture the repeated pattern **again** along with your new notes. To record only a new part, silence/unprogram the duplicated sequencer notes or use a different bank. Turn the track playback down while recording only if you do not need to monitor it: the overdub math uses the stored original buffer and is independent of its track fader.

The old recorded track is resampled at the *current transport BPM* and exact bar phase before summing it with the new PCM. This means overdubbing at a different tempo bakes in the tape-rate pitch change into the newly saved combined track. The mix uses clipped stereo summation to avoid values beyond [-1,1], so multiple heavy overdubs can distort. Start with a moderate layer gain and keep your sources below full scale.

## Undo, redo and replace

- **UNDO** restores the previous recording on that track. **REDO** restores the version you just backed out of.
- History is **one level per track** in current browser memory. A new REC LOOP, REPLACE or OVERDUB replaces that track's history. Closing/reloading PhiBox clears history, even though the current take is preserved in local IndexedDB.
- **REPLACE** records an entirely fresh loop take and now also supports the same single-level undo, so you can undo a replacement.
- **CLEAR** removes the audio and clears the temporary undo/redo history for that track. It also deletes the take from local IndexedDB.
- Stopping the transport stops playback but does not erase the finished audio.

## Export a loop lane as WAV

Every recorded track shows a **WAV** button. It exports the stored original-speed stereo 16-bit PCM directly, without other tracks mixed in. The original capture BPM and number of bars are included in the filename. The master **RESAMPLE → CHOP SHOP** button remains available for capturing the fully processed ensemble.

**Note:** individual WAV export is an audio file, independent of the project's JSON settings export. JSON **never** contains loop PCM or sample source files; take backups of valuable recordings.

## Technical boundaries

R6 remains a browser groovebox, not VST3/CLAP/AU, a DAW with audio interfaces, or a multitrack destructive editor. There is not yet a separate punch-in/out area, independent per-loop FX inserts, automatic input isolation by sequencer track, or unlimited/history-persistent overdub undo. AudioWorklet and Web Audio are required for captures; automated tests exercise phase alignment and accumulation math, but hands-on audio QA still matters.
